CHANGE. src/generate.py: new meta_rewrite() plus _meta_sentences(). When meta_violations() (the ban's own matcher) flags text, the same model/config is re-asked, up to META_REWRITE_ATTEMPTS = 2 times, to rewrite ONLY the offending sentences, with the banned terms named. Each clean one-line rewrite is spliced back in place of its sentence. A sentence the model could not clean is left unchanged, never deleted. The candidate is kept only if fewer sentences offend and the caller's keep check holds: for chapter blocks, no entry lost and no new template fault; for feats, no entity lost and no traced deed lost. This is wired into chapter blocks (before assert_block_complete, so every block gate judges the rewritten text), feats blocks (before the deed trace) and frontmatter. If the model call fails, the text is returned unchanged and silence.note("generate.py:meta-rewrite-failed") is recorded. main()'s guarded assert_in_universe try/except is untouched, and the ban regex is untouched.
